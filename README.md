# Agent + RAG 学习辅助系统

## 一、项目简介

本项目是一个基于 **Agent + RAG** 技术构建的学习辅助系统，主要用于解决课程实验中常见的资料分散、代码理解困难、实验报告撰写效率低、运行问题定位不清晰等问题。

系统支持上传实验文档、代码文件或报告资料，通过文本切分、向量化存储、相似度检索和大模型推理，为用户提供文档问答、代码解释、实验总结、问题定位和学习内容梳理等功能。同时，系统加入了简单的历史记忆机制，可以保存最近的问答记录，并在后续回答中辅助生成更连贯的结果。

## 二、核心功能

1. **文档问答**  
   上传 PDF、Word、TXT、Markdown 等资料后，可以直接针对文档内容进行提问。

2. **代码解释**  
   支持上传 Python、C/C++、Java、JavaScript 等代码文件，系统可以解释整体功能、关键模块和核心流程。

3. **实验总结**  
   可根据上传资料自动生成实验目的、实验过程、实验结果、问题分析和实验小结。

4. **问题定位**  
   用户可以输入报错信息或运行问题，系统会结合上传资料给出可能原因和解决步骤。

5. **历史记忆**  
   系统会保存最近 20 条问答记录，后续提问时会自动检索相关历史内容辅助回答。

## 四、环境要求

建议使用 Python 3.9 及以上版本。

需要安装以下依赖：

```bash
pip install gradio openai python-dotenv faiss-cpu numpy pypdf python-docx
```

如果使用 Anaconda，也可以先创建独立环境：

```bash
conda create -n agent_rag python=3.10
conda activate agent_rag
pip install gradio openai python-dotenv faiss-cpu numpy pypdf python-docx
```

## 五、配置 API Key

在项目根目录下新建 `.env` 文件，内容如下：

```env
OPENAI_API_KEY=你的API_KEY
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini
```

如果使用的是兼容 OpenAI API 格式的第三方平台，需要根据平台提供的信息修改：

```env
OPENAI_API_KEY=你的API_KEY
OPENAI_BASE_URL=你的接口地址
OPENAI_MODEL=你的模型名称
```

注意：代码中默认使用的 Embedding 模型为：

```text
text-embedding-3-small
```

如果第三方平台不支持该 Embedding 模型，需要在 `learning_agent_rag.py` 中修改：

```python
EMBEDDING_MODEL = "text-embedding-3-small"
```

## 六、运行方式

在项目目录下执行：

```bash
python learning_agent_rag.py
```

启动成功后，终端会显示类似信息：

```text
============================================================
Agent + RAG 学习辅助系统
============================================================
正在启动 Web 界面...
Running on local URL:  http://127.0.0.1:7860
```

然后在浏览器中打开：

```text
http://127.0.0.1:7860
```

## 七、使用步骤

1. 启动程序后，进入 Web 页面。
2. 点击左侧上传实验文档或代码文件。
3. 点击“构建知识库”。
4. 等待系统完成文本读取、切分和向量库构建。
5. 在右侧输入问题，例如：

```text
请解释这段代码的核心流程。
```

```text
根据上传的实验文档生成一份实验总结。
```

```text
为什么运行时出现模块找不到的问题？
```

```text
请根据资料说明本实验的目的和步骤。
```

6. 系统会自动判断任务类型，并结合检索到的资料生成回答。

## 八、系统工作流程

系统整体流程如下：

```text
用户上传文件
    ↓
读取文件内容
    ↓
文本切分为 chunk
    ↓
调用 Embedding 模型生成向量
    ↓
使用 FAISS 建立向量索引
    ↓
用户输入问题
    ↓
Agent 判断任务类型
    ↓
向量库检索相关资料片段
    ↓
检索历史记忆
    ↓
构造 Prompt
    ↓
调用大模型生成答案
    ↓
保存本轮问答到历史记忆
```

## 十、项目亮点

1. **结合 RAG 技术**  
   系统不是直接让大模型凭空回答，而是先从用户上传资料中检索相关内容，再基于资料生成答案，可以减少幻觉。

2. **具备 Agent 思想**  
   系统会先判断用户问题属于文档问答、代码解释、实验总结、问题定位还是通用学习问答，再采用不同的回答要求。

3. **加入历史记忆机制**  
   系统会保存最近问答记录，使后续回答可以参考历史上下文，提高连续使用体验。

4. **适合课程实验场景**  
   系统的回答格式针对学生实验场景设计，便于生成实验报告、代码说明和问题分析内容。

## 十一、常见问题

### 1. 网页无法打开怎么办？

请确认终端中显示的地址是：

```text
http://127.0.0.1:7860
```

不要直接访问：

```text
http://0.0.0.0:7860
```

`0.0.0.0` 是服务监听地址，不一定适合直接在浏览器中访问。本代码已经将启动地址设置为 `127.0.0.1`。

### 2. 提示 API Key 错误怎么办？

请检查 `.env` 文件是否存在，以及 `OPENAI_API_KEY` 是否填写正确。

### 3. 上传文件后构建知识库失败怎么办？

可能原因包括：

- 文件为空；
- 文件编码不支持；
- PDF 无法正确提取文字；
- API Key 或 Embedding 模型配置错误；
- 网络无法访问模型接口。

### 4. 使用第三方模型平台时报错怎么办？

需要确认该平台是否同时支持：

- Chat Completions 接口；
- Embeddings 接口；
- 当前填写的模型名称。

如果平台不支持 `text-embedding-3-small`，需要替换为平台支持的 Embedding 模型。
